# music-downloader (python)
music downloader via terminal. you can download it from url (YouTube, YouTube Music, SoundCloud, Bandcamp, TikTok, Instagram, dan Vimeo) or search the music title.

## feature

- download music from url
- search music title

## requirement

- python 3.12
- pip
- make sure you run it in directory you want to save the music
